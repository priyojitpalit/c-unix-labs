# Operating Systems Practical Examination

Work in the `os_practical_exam` directory of the course Binder environment. The numbered sections correspond to the Canvas examination. Use a **terminal** to run commands, compile C code, and test your solutions. Submit only the responses requested in Canvas.

The file contents and directory structure are part of the examination. Do not modify any supplied `.log` or `.txt` input files. You may edit C source files in `06_c_arrays`, `07_c_structs`, and the Makefile and `totals.c` file in `05_make` as instructed by the examination.

For numerical answers enter the requested integer, without extra text. Perform the tasks in their given order, particularly the compilation and Makefile tasks. Code that has not been completed will not produce correct output for the C questions.

All questions use commands and C concepts previously introduced. You do not need `awk`, Python, or additional software. The sample files contain enough records that command-line processing is preferable to manual inspection.
